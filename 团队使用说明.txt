专利创新估值项目 - 组员本地运行说明
================================

一、环境要求
  - Windows 10/11
  - Python 3.10 或以上（安装时勾选 Add to PATH）
  - MySQL 8.0（本机安装，不用 Docker）

二、解压后安装步骤
  1. 解压到例如 C:\Users\你的用户名\patent-valuation-agent
  2. 复制 .env.example 为 .env（默认不用改）
  3. 打开 PowerShell，进入项目目录：
       cd 项目路径
       python -m venv .venv
       .\.venv\Scripts\activate
       pip install -r requirements.txt
  4. 初始化数据库（输入本机 MySQL 的 root 密码）：
       python scripts\setup_db.py
  5. 测试：
       python scripts\check_db.py
       python scripts\run_innovation_agent.py CN202310001234.5
       python scripts\run_scene_agent.py CN202310001234.5

三、常见问题
  - 连不上数据库：打开 services.msc，启动 MySQL80 服务
  - 没有 patent 用户：重新运行 setup_db.py

四、启用 DeepSeek（可选）
  1. 打开 https://platform.deepseek.com/api_keys 创建 API Key
  2. 复制 .env.example 为 .env，填写：
       OPENAI_API_KEY=sk-你的密钥
       OPENAI_BASE_URL=https://api.deepseek.com
       OPENAI_MODEL=deepseek-chat
  3. python scripts\test_deepseek.py
  4. python scripts\run_innovation_agent.py CN202310001234.5
     输出 method 为 llm 即表示已走大模型

五、Docker 一键部署（推荐答辩演示）
  1. 安装 Docker Desktop
  2. 项目根目录执行:
       docker compose up -d --build
  3. 等待 MySQL 健康后访问:
       http://localhost:8000/health
       http://localhost:8000/valuate/CN202320045678.9
  4. 完整流水线（命令行）:
       docker compose exec app python main.py CN202320045678.9
  报告输出在 ./reports/

七、从本地文件直接估值（无需数据库里有该专利）
  python run_from_file.py samples/patent_example.txt
  或:
       python main.py -f samples/patent_example.txt
  文件格式见 samples/patent_example.txt（标题/摘要/权利要求等字段）
  可选同名 .meta.json 补充引用次数、行业参数（见 patent_example.meta.json）
  PDF: pip install pypdf 后 python run_from_file.py 你的文件.pdf

六、主要代码目录
  src/agents/innovation.py   创新程度 Agent
  src/agents/scene.py        应用场景 Agent
  src/agents/market.py       市场环境 Agent
  src/agents/value.py        价值整合 Agent
  src/agents/valuation.py    估值 Agent
  src/agents/report.py       报告生成 Agent
  src/agents/pipeline.py     多 Agent 流水线
  api.py                     FastAPI 服务入口
  db/init/                   建表与样例数据 SQL
  scripts/                   安装与单独测试脚本
